# 寻迹诗旅 · 《用户隐私保护指引》填写清单与文案

> 用途：直接对照本清单填写到微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」。
> 核对日期：2026-10-15（依据当前代码 `miniprogram/` 与 `miniprogram/cloudfunctions/` 实测）。

---

## 一、处理的信息（勾选 + 目的说明）

按微信后台实际展示的必填项勾选，逐项填写「目的」。以下为对照当前代码的准确文案。

### 1. OpenID（用户身份标识）
- **对应接口/能力**：`wx.login`（换取 code → 云端 code2session 得 OpenID）
- **目的文案**：
  > 用于识别用户身份，把用户的通关进度、知识锚点、探究档案等学习数据同步到云端，实现「换设备不丢学习档案」。
- **存储位置**：微信云数据库 `users` 集合
- **保存期限**：保存至用户主动「删除学习档案」为止；无固定期限，用户可随时删除

### 2. 昵称
- **来源**：用户在本小程序「我的」页自行输入（非微信头像昵称，非 `getUserProfile`）
- **存储位置**：仅保存在本机本地缓存（`userNickname`），**不上传云端**
- **目的文案**：
  > 用于在诗笺等学习成果展示中称呼用户。昵称仅保存在用户本机，不向云端或第三方传输。
- **删除方式**：删除学习档案或清理本小程序缓存

### 3. 学习进度
- **内容**：通关状态、知识锚点、探究档案（含诗笺记录）
- **存储位置**：微信云数据库 `users` 集合 `progress` 字段
- **目的文案**：
  > 用于保存并跨设备同步用户的学习进度、知识锚点与探究档案，避免换设备后进度丢失。
- **删除方式**：「我的 → 删除学习档案」（永久删除云端身份记录与本机数据），或「清除进度，重新开始」

### 4. AI 对话内容（生成式 AI 功能）
- **处理链路**（据 `cloudfunctions/chat/index.js`）：
  1. 用户输入的对话文本，先经微信内容安全接口 `security.msgSecCheck` 检测；
  2. 通过后实时发送给 DeepSeek（模型 `deepseek-chat`）生成回复；
  3. AI 生成回复再次经微信内容安全检测后返回给用户。
- **留存说明（据当前代码，如实填写）**：
  > 本小程序**不持久化保存**用户与 AI 的对话记录（当前版本对话历史不落库，仅用于当次生成回复）。
  > 对话文本会实时发送给第三方大模型服务商 DeepSeek，其数据处理与留存以 DeepSeek 官方隐私政策为准。
- **⚠️ 待确认项**：正式填写前请到 DeepSeek 官方隐私政策/用户协议核对「是否留存、保存期限、删除规则」，并在「第三方服务商信息」或补充说明中如实描述，**切勿写「绝不保存」「立即删除」等无法从第三方政策佐证的绝对承诺**。

### 5. 保存诗笺（相册写入）
- **对应接口**：`wx.saveImageToPhotosAlbum`
- **触发时机**：仅在用户主动点击「保存为图片」时调用
- **目的文案**：
  > 用于把用户在学习过程中生成的竖版诗笺图片保存到用户相册，仅在用户主动点击「保存为图片」时访问相册。

## 二、剪切板（必填 · 据历史提审记录）

### 6. 剪切板（`wx.setClipboardData`）
- 现状：`pages/poem/poem.js` 两处用到 `wx.setClipboardData`——「复制文案」（`onCopy`）和保存图片失败时的降级复制（`degradeToCopy`），均为**写入**（非读取）。
- 依据：微信官方《小程序用户隐私保护指引内容介绍》把 `wx.setClipboardData` 与 `wx.getClipboardData` 一并归入「读取你的剪切板」类别；**该声明项一旦使用即不可删除，只能填写使用说明**（上一轮提审已被此卡住）。
- **目的文案（建议）**：
  > 用于复制用户生成的诗笺文案。仅在用户主动点击「复制文案」或保存图片失败需降级复制时，把文本写入系统剪贴板；不读取用户剪贴板中的任何内容。

## 四、保存期限与删除方式（汇总文案，可直接粘贴）

> **信息保存期限**：OpenID 与学习进度保存至用户主动删除学习档案为止；昵称仅保存在本机，随清理缓存或删除档案而删除；AI 对话记录本小程序不持久化保存。
> **删除方式**：用户可在「我的 → 删除学习档案」永久删除云端身份记录、学习进度与本机数据；也可在「我的 → 清除进度，重新开始」清空全部学习进度。
