## 一、功能结果：用户现在能做什么

1. 首次选杜甫时创建一次角色（三选一外观 + 自定义姓名 1–8 字），之后 **22 个地点全程沿用同一份档案**，不再重复创建；泰山不再弹「这一程，你是谁」。
2. 玩家说话时用自己的姓名与所选外观；外观只影响立绘，**不改变任何剧情、选项、知识锚点、奖励或 AI 亲疏**。
3. 顶部只有一行「同行者 · 姓名」，没有职业、信任称号、关系等级或好感数值。
4. 「我的」页有「杜甫线 · 我的角色」卡片：无档案 → 创建；迁移草稿 → 确认；已确认 → 编辑；档案损坏 → 修复。账号昵称与角色名互不影响。
5. 与杜甫自由对话时，他只记得**当时已经发生**的共同经历；未必发生的分支、未来地点与晚年诗作不会提前泄露。重温早期地点不会带出后期记忆。
6. 地点配音按 `地点/节点` 定位；只有 NPC 台词发声，玩家发言、动作与旁白不播。台词改过而音频未重录时**主动跳过旧音频**，不播错词。
7. 终章收束显示「同行者：姓名」与一段基于必经事件的回望；三种外观得到完全相同的终章正文。
8. 重温使用当前角色，严格只读：不写检查点、地点状态、诗笺、锚点、任务、通关时间与角色档案；退出后继续正式旅程仍在原位置。
9. 李白、苏轼保持原状，不显示杜甫角色、不继承其记忆。

## 六、发布顺序与回退

详见 `docs/杜甫角色-发布准备与回退清单.md`。要点：

**顺序**：先部署 `story`（含 `playerProfiles` 合并）→ 再部署 `chat`（含 memory/scenes/fallback）→ 核对云库老档案 → 上传/核对素材 → 四类账号跑体验版 → 发布客户端 → 观察 48 小时。

可单点关闭：`ROLE_LINES=[]`（角色入口）、跳过 `availableMemories`（AI 记忆）、`resolveAudioQuestId` 返回空串（配音）、`shouldShowRecap` 返回 false（终章回望）。
**严禁**：清空 `playerProfiles`、把 `avatarId` 当旧 `roleId` 写回、删除 `locationProfiles` / `locationStates` / 新录音频。
